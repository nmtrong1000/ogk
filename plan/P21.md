# P21: Refactor ogk-dashboard

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P20 |
| App | ogk-dashboard |

## Mục tiêu

Thiết lập Vitest cho unit test, Playwright cho E2E với API được mock, và Lucide React cho icon. Sau đó duyệt giao diện theo từng screen: trình bày một screen, nhận yêu cầu chỉnh sửa, hoàn tất và chờ user chốt screen đó trước khi chuyển sang screen kế tiếp.

Animation và state management không nằm trong phạm vi mặc định của phase này; chỉ cân nhắc thư viện mới nếu phát sinh yêu cầu cụ thể.

## Kiểm tra nghiệm thu

- Có lệnh chạy unit test Vitest và E2E Playwright.
- E2E kiểm tra chức năng chính của screen bằng API mock, không phụ thuộc server thật.
- Lucide React được cài và có thể dùng trong dashboard.
- 20 route ứng dụng và trang 404 đều được duyệt lần lượt; `/design` chỉ dành cho dev nên không thuộc phạm vi.
- Với từng screen, chỉ chuyển tiếp sau khi user chốt giao diện; các yêu cầu chỉnh sửa được xử lý và kiểm tra trên chính screen đó trước.
- Kiểm tra lint, format và build theo WORKFLOW.md.
