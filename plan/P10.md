# P10: Chính sách

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P7, P8 |
| App | ogk-server, ogk-agent/service |

## Mục tiêu

Chính sách theo từng trẻ có policy_version, được ký Ed25519 trên JSON chuẩn hóa. Khóa bí mật của server không nằm trong mã nguồn. Agent tải chính sách của mọi trẻ gắn với thiết bị, kiểm tra chữ ký và lưu bản hợp lệ gần nhất. Mọi thay đổi chính sách được ghi nhật ký kiểm toán. Phase này làm phần vỏ chính sách và test bằng một trường mẫu.

## Kiểm tra nghiệm thu

- Sửa trường mẫu qua API thì policy_version tăng và có một dòng nhật ký.
- Sửa một byte chính sách trong DB cục bộ thì agent từ chối.
- Khởi động lại service thì agent tải chính sách mới nhất.
- Test của server và agent cùng qua `docs/test_vectors.json`.

## Kết quả

Agent tải và kiểm tra được chính sách đã ký.

## Phase con và task

ID phase con dạng P10.n theo thứ tự app. ID task dạng P10.n.k.
