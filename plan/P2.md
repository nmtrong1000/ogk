# P2: Scaffold Dashboard

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P1 |
| App | ogk-server, ogk-dashboard |

## Mục tiêu

Dựng khung app React bằng Vite và TypeScript: một trang trống gọi được OGK-Server qua proxy của Vite khi phát triển; bản build được FastAPI phục vụ cùng origin với API. Chưa có chức năng nào.

## Kiểm tra nghiệm thu

- Chạy Vite thì trang trống hiện trạng thái lấy từ `/api/health` qua proxy.
- Sau khi build, mở trang qua HTTPS của OGK-Server trên trình duyệt máy tính và điện thoại, không có cảnh báo chứng chỉ.

## Kết quả

Dashboard mở được qua HTTPS của OGK-Server, cùng origin với API.

## Phase con và task

ID phase con dạng P2.n theo thứ tự app. ID task dạng P2.n.k.

### P2.1: ogk-server

| ID | Task | Xong khi |
| :---- | :---- | :---- |

### P2.2: ogk-dashboard

| ID | Task | Xong khi |
