# P7: Nhật ký kiểm toán

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P6 |
| App | ogk-server, ogk-dashboard |

## Mục tiêu

Mọi thay đổi do phụ huynh thực hiện đều được ghi: ai, lúc nào, từ IP nào, giá trị cũ, giá trị mới. Phụ huynh xem nhật ký của mình trên dashboard; admin xem toàn hệ thống.

## Kiểm tra nghiệm thu

- Sửa thông tin trẻ thì có một dòng nhật ký đủ 5 trường.
- Không có API nào sửa hoặc xóa được nhật ký.
- Phụ huynh chỉ thấy nhật ký của mình.

## Kết quả

Dashboard có trang nhật ký kiểm toán.

## Phase con và task

ID phase con dạng P7.n theo thứ tự app. ID task dạng P7.n.k.

### P7.1: ogk-server

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P7.1.1 | Model nhật ký: người thực hiện, thời điểm, IP, đối tượng, giá trị cũ, giá trị mới; chỉ cho thêm | Không có đường sửa hoặc xóa |
| P7.1.2 | Hàm ghi nhật ký để các module khác gọi qua `service.py` của audit | Có test ghi nhật ký |
| P7.1.3 | Lấy IP của request | IP đúng khi gọi qua proxy của Vite và khi gọi thẳng |
| P7.1.4 | Ghi nhật ký cho thêm, sửa, xóa trẻ | Mỗi thao tác có một dòng |
| P7.1.5 | API liệt kê nhật ký có phân trang; phụ huynh thấy của mình, admin thấy toàn hệ thống | Có test phân quyền |

### P7.2: ogk-dashboard

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P7.2.1 | `features/audit`: trang nhật ký có phân trang | Xem được trên điện thoại |
| P7.2.2 | Hiện giá trị cũ và mới dễ đọc | Không hiện JSON thô |
