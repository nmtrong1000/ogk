# P20: Kiểm thử hồi quy trên máy ảo Windows

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P18 |
| App | ogk-agent/service, ogk-agent/tray |
| Kiểm thử | Toàn bộ trên bản clone sạch của máy ảo Windows 11 ARM; pytest trên Mac sau mỗi lần sửa |

## Mục tiêu

Máy ảo Windows 11 ARM đã được dựng trong P12: UTM, tài khoản admin và tài khoản trẻ chuẩn, bản clone sạch, SSH bằng khóa từ Mac, Python 3.12 x64, build và cài agent bằng `installer/`. Từ P13 mỗi phase đã kiểm tra phần của mình trên máy ảo. P20 không thêm tính năng: cài mới agent trên bản clone sạch, chạy lại mọi mục nghiệm thu liên quan máy trẻ của P8 đến P19 để bắt lỗi hồi quy giữa các phase, và kiểm tra những mục không thuộc phase chức năng nào: Service Recovery, quyền của tài khoản trẻ, độ chính xác của bộ đếm, gỡ cài đặt.

## Kiểm tra nghiệm thu

- Trên bản clone sạch, cài agent bằng một lệnh và ghép đôi bằng mã từ dashboard.
- Service hiện trong Services.msc, chạy và dừng được, không treo khi dừng; kill tiến trình service thì Windows tự bật lại.
- Đăng nhập tài khoản trẻ thì thấy biểu tượng khay và thông báo khởi động; kill Tray UI thì nó hiện lại.
- Tài khoản trẻ không đọc và không ghi được DB cục bộ và thư mục cấu hình của agent.
- Sai số đếm giờ không quá 30 giây mỗi giờ so với đồng hồ bấm tay.
- Mọi mục nghiệm thu có nhãn (máy ảo) của P13 đến P19 và mục nghiệm thu P12 vẫn qua khi tất cả module cùng chạy.
- Gỡ agent bằng một lệnh thì service, tệp, DNS và luật tường lửa được hoàn trả; mạng vẫn dùng được.
- pytest của agent vẫn qua trên Mac sau khi sửa lỗi.

## Kết quả

Bản agent cuối cùng chạy đúng trên máy ảo Windows khi cài mới từ đầu, sẵn sàng cho nghiệm thu ở P21.

## Phase con và task

ID phase con dạng P20.n theo thứ tự app. ID task dạng P20.n.k.

### P20.1: ogk-agent/service

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P20.1.1 | Clone lại máy ảo từ bản sạch; cài Python 3.12 x64, build và cài agent, ghép đôi | Service chạy, log ghi trạng thái server và version chính sách đã tải |
| P20.1.2 | Kiểm tra Start, Stop trong Services.msc và Service Recovery | Không treo khi dừng; kill tiến trình thì SCM bật lại |
| P20.1.3 | Kiểm tra ACL thư mục dữ liệu và DPAPI bằng tài khoản trẻ | Tài khoản trẻ không mở được DB và cấu hình |
| P20.1.4 | Chạy lại mọi mục nghiệm thu liên quan máy trẻ của P12 đến P19 trên cùng một bản cài | Mọi mục qua |
| P20.1.5 | Gỡ cài đặt, kiểm tra service, tệp, DNS card mạng và luật tường lửa đã được hoàn trả | Mạng dùng được, không còn dấu vết của agent |
| P20.1.6 | Sửa lỗi hồi quy, chạy lại pytest trên Mac và cập nhật agent trên máy ảo | pytest qua và mục lỗi qua trên máy ảo |

### P20.2: ogk-agent/tray

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P20.2.1 | Kill Tray UI trong phiên của trẻ; kiểm tra service bật lại và cưỡng chế không bị tắt | Tray UI hiện lại |
| P20.2.2 | Đo sai số đếm giờ trong 1 giờ so với đồng hồ bấm tay, ghi số liệu | Sai số không quá 30 giây |
