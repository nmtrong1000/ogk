# P20: Kiểm thử trên Windows

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P18 |
| App | ogk-agent/service, ogk-agent/tray |

## Mục tiêu

Dựng máy ảo Windows 11 ARM, build và cài agent, kiểm tra mọi phần gọi API Windows trong `platform/` của service và tray. Sửa lỗi chỉ xuất hiện trên Windows. Phase này không thêm tính năng mới.

## Kiểm tra nghiệm thu

- Python 3.12 x64 và mọi thư viện của agent import được dưới giả lập x64.
- Cài và gỡ service bằng một lệnh.
- Service hiện trong Services.msc, chạy và dừng được, không treo khi dừng.
- Kill tiến trình service thì Windows tự bật lại.
- Service ghi log vào `C:\ProgramData\OGK\logs` và gọi `/api/health` của OGK-Server qua HTTPS thành công.
- Đăng nhập tài khoản trẻ thì thấy biểu tượng khay và thông báo khởi động; kill Tray UI thì nó hiện lại.
- Tài khoản trẻ không đọc và không ghi được DB cục bộ và thư mục cấu hình của agent.
- Quota 3 phút thì máy bị khóa bằng LockWorkStation; trẻ đăng nhập lại khi vẫn hết giờ thì bị khóa lại trong 5 giây.
- Sai số đếm giờ không quá 30 giây mỗi giờ so với đồng hồ bấm tay.
- Đổi tên notepad.exe thành game.exe vẫn bị nhận diện và chặn; không bao giờ kết thúc tiến trình hệ thống quan trọng.
- nslookup và trình duyệt xác nhận lọc tên miền và SafeSearch.
- Gọi thẳng DNS bên ngoài như 8.8.8.8, qua IPv6 hoặc qua cổng 853 đều bị chặn.
- Dừng hoặc gỡ agent thì mạng vẫn dùng được.
- pytest của agent vẫn qua trên Mac sau khi sửa lỗi.

## Kết quả

Agent chạy đúng trên Windows như trên Mac.

## Phase con và task

ID phase con dạng P20.n theo thứ tự app. ID task dạng P20.n.k.

### P20.1: ogk-agent/service

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P20.1.1 | Dựng máy ảo Windows 11 ARM trong UTM hoặc Parallels; tạo tài khoản admin và tài khoản trẻ chuẩn | Tài khoản trẻ không thuộc nhóm Administrators |
| P20.1.2 | Chụp snapshot sạch của máy ảo | Khôi phục được snapshot |
| P20.1.3 | Cài Python 3.12 x64, cài requirements, chạy script kiểm tra import | Import đủ thư viện dưới giả lập x64 không lỗi |
| P20.1.4 | Build `ogk-service.exe`, cài bằng script trong `installer/` | Service chạy, log ghi trạng thái server |
| P20.1.5 | Kiểm tra Start, Stop trong Services.msc và Service Recovery | Không treo khi dừng; kill tiến trình thì SCM bật lại |
| P20.1.6 | Kiểm tra `platform/session.py` và bật Tray UI trong phiên của trẻ | Log ghi đúng từng sự kiện phiên; Tray UI chạy dưới tài khoản trẻ |
| P20.1.7 | Kiểm tra `platform/dpapi.py` và ACL thư mục dữ liệu | Tài khoản trẻ không mở được DB |
| P20.1.8 | Kiểm tra `platform/process.py` với luật ứng dụng | Đổi tên tệp vẫn bị chặn |
| P20.1.9 | Kiểm tra `platform/netconfig.py` và `platform/firewall.py` với DNS proxy tại cổng 53 | Gọi thẳng 8.8.8.8 bị chặn; dừng service thì mạng vẫn dùng được |
| P20.1.10 | Sửa lỗi chỉ xuất hiện trên Windows, chạy lại pytest trên Mac | pytest qua |
