# P9: Hiện diện của agent

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P4 |
| App | ogk-agent/service, ogk-agent/tray |

## Mục tiêu

Biểu tượng khay luôn hiện khi agent chạy, có thông báo khi agent khởi động. Service nhận SESSIONCHANGE, bật Tray UI trong phiên của trẻ và bật lại khi bị tắt. Bật lại thất bại nhiều lần thì service tắt trạng thái cưỡng chế và ghi log cục bộ.

## Kiểm tra nghiệm thu

- Chạy agent trên Mac thì service bật Tray UI, thấy biểu tượng khay và thông báo khởi động.
- Kill Tray UI thì nó hiện lại.
- Ngăn Tray UI chạy thì service chuyển trạng thái cưỡng chế sang tắt, ghi log cục bộ và trả trạng thái này qua IPC.

## Kết quả

Trẻ luôn biết agent đang chạy.

## Phase con và task

ID phase con dạng P9.n theo thứ tự app. ID task dạng P9.n.k.

### P9.1: ogk-agent/service

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P9.1.1 | `platform/session.py`: nhận SERVICE_CONTROL_SESSIONCHANGE khi đăng nhập, đăng xuất, khóa, mở khóa; bản giả cho Mac phát sự kiện phiên | Log ghi đúng từng sự kiện phiên giả |
| P9.1.2 | Bật Tray UI trong phiên của trẻ bằng WTSQueryUserToken và CreateProcessAsUser; bản giả cho Mac bật Tray UI bằng tiến trình con | Service bật được Tray UI trên Mac |
| P9.1.3 | `modules/presence`: theo dõi tín hiệu sống của Tray UI, bật lại khi mất, đếm số lần thất bại | Kill Tray UI thì hiện lại |
| P9.1.4 | Trạng thái cưỡng chế trong `core/`: thất bại nhiều lần thì tắt, ghi log, trả qua IPC | Đọc được trạng thái qua IPC |

### P9.2: ogk-agent/tray
