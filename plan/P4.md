# P4: Scaffold Tray UI

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P3 |
| App | ogk-agent/service, ogk-agent/tray |

## Mục tiêu

Dựng kênh IPC trong service và khung Tray UI: hiện biểu tượng khay, mở được cửa sổ trống, gọi được Agent Service qua 127.0.0.1 có token. Code chạy và kiểm tra trên Mac; `tray/platform` có bản giả cho Mac. Chưa có chức năng nào.

## Kiểm tra nghiệm thu

- Chạy Tray UI trên Mac thì thấy biểu tượng khay.
- Bấm biểu tượng thì mở cửa sổ trống hiện trạng thái service.
- Request tới kênh IPC không có token bị từ chối.

## Kết quả

Cả 4 app chạy được trên Mac và kết nối được với nhau.

## Phase con và task

ID phase con dạng P4.n theo thứ tự app. ID task dạng P4.n.k.

### P4.1: ogk-agent/service

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P4.1.1 | `core/ipc_server.py`: HTTP tại 127.0.0.1 chạy trong event loop, endpoint kiểm tra | curl trên Mac trả 200 |
| P4.1.2 | Sinh token cục bộ khi service khởi động; ghi tệp token cho người dùng đọc được nhưng không ghi được | Request thiếu token bị từ chối |

### P4.2: ogk-agent/tray

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P4.2.1 | Biểu tượng khay bằng pystray, menu mở cửa sổ tkinter trống | Thấy biểu tượng khi chạy tay |
| P4.2.2 | `ipc_client.py` đọc token và gọi endpoint kiểm tra của service | Cửa sổ hiện trạng thái service |
| P4.2.3 | `tray/platform`: nơi duy nhất của tray gọi API Windows, có bản giả cho Mac | Tray UI chạy trên Mac |
| P4.2.4 | Script build `ogk-tray.exe` bằng PyInstaller x64 và thêm vào script cài đặt | Có script |
