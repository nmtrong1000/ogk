# P18: Lưu trữ và xóa dữ liệu (F3)

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P17 |
| App | ogk-server, ogk-dashboard, ogk-agent/service |
| Kiểm thử | pytest trên Mac; mục có nhãn (máy ảo) chạy trên máy ảo Windows 11 ARM, đăng nhập tài khoản trẻ |

## Mục tiêu

Tác vụ tự động xóa dữ liệu cũ hơn 90 ngày trên server và agent. Nút "Xóa toàn bộ dữ liệu của con tôi" xóa trên server và gửi lệnh xóa bộ đệm tới agent. Hoàn thiện PRIVACY.md.

## Kiểm tra nghiệm thu

- Dữ liệu mẫu 91 ngày tuổi bị xóa trên server và agent (máy ảo).
- Bấm "Xóa toàn bộ dữ liệu của con tôi" thì dữ liệu mất trên cả server và agent (máy ảo).
- Mọi trường trong DB có trong bảng của PRIVACY.md.

## Kết quả

Dữ liệu của trẻ được giữ đúng thời hạn và xóa được theo yêu cầu.

## Phase con và task

ID phase con dạng P18.n theo thứ tự app. ID task dạng P18.n.k.

### P18.1: ogk-server

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P18.1.1 | Tác vụ hằng ngày xóa sự kiện, cảnh báo, yêu cầu và lệnh cũ hơn 90 ngày | Có test với dữ liệu mẫu có thời điểm cũ |
| P18.1.2 | API xóa toàn bộ dữ liệu của trẻ; tạo lệnh xóa bộ đệm cho mọi thiết bị của trẻ; ghi nhật ký kiểm toán | Có test xóa |
| P18.1.3 | Hoàn thiện PRIVACY.md: trường dữ liệu, mục đích, thời hạn lưu, ai xem được; bỏ trường không giải thích được | Mọi trường trong DB có trong bảng |
