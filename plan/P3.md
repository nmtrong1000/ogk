# P3: Scaffold Agent Service

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P1 |
| App | ogk-agent/service |

## Mục tiêu

Dựng khung Agent Service chạy asyncio, ghi log, gọi được OGK-Server. Code chạy và kiểm tra trên Mac bằng bản giả của `platform/`. Code Windows Service, script build, cài và gỡ được viết sẵn và kiểm tra trên Windows ở P20. Chưa có chức năng nào.

## Kiểm tra nghiệm thu

- Cài thư viện của agent trên Mac bằng một lệnh.
- Chạy agent trên Mac bằng một lệnh; agent ghi log và gọi `/api/health` của OGK-Server qua HTTPS thành công.
- Ctrl+C thì agent dừng sạch, không treo.
- Phần logic chạy được pytest trên Mac mà không cần pywin32.

## Kết quả

Agent Service chạy được trên Mac và kết nối được tới OGK-Server.

## Phase con và task

ID phase con dạng P3.n theo thứ tự app. ID task dạng P3.n.k.

### P3.1: ogk-agent/service

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P3.1.1 | Tạo ogk-agent với requirements.txt và cấu trúc `service/core`, `service/modules`, `service/platform` theo PLAN.md; pywin32 và PyInstaller chỉ cài trên Windows | Cài đặt trên Mac bằng một lệnh |
| P3.1.2 | Bản giả của `platform/` chạy agent trên Mac, dừng bằng Ctrl+C | Chạy agent trên Mac bằng một lệnh |
| P3.1.3 | Agent chạy asyncio event loop, dừng sạch khi có yêu cầu dừng | Có test dừng |
| P3.1.4 | Ghi log vào thư mục `logs` trong thư mục dữ liệu của agent | Có log khi agent chạy |
| P3.1.5 | Gọi `/api/health` của server qua HTTPS bằng CA tự ký | Log ghi trạng thái server |
| P3.1.6 | `platform/windows.py`: Windows Service bằng win32serviceutil, dữ liệu tại `C:\ProgramData\OGK`, dừng sạch khi SCM yêu cầu | Có code |
| P3.1.7 | Script build `ogk-service.exe` bằng PyInstaller x64, script cài và gỡ service trong `installer/`, cấu hình Service Recovery | Có script |
| P3.1.8 | Script kiểm tra import đủ thư viện của agent | Chạy qua trên Mac |
| P3.1.9 | Test logic trên Mac | pytest qua |
