# P3: Scaffold Agent Service

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P1 |
| App | ogk-agent/service |

## Mục tiêu

Dựng máy ảo Windows 11 ARM có tài khoản trẻ không thuộc nhóm Administrators. Dựng khung Windows Service chạy asyncio, cài và gỡ được, ghi log, gọi được OGK-Server. Kiểm tra sớm Python 3.12 x64 và các thư viện chạy được dưới giả lập x64. Chưa có chức năng nào.

## Kiểm tra nghiệm thu

- Cài và gỡ service bằng một lệnh.
- Service hiện trong Services.msc, chạy và dừng được, không treo khi dừng.
- Kill tiến trình service thì Windows tự bật lại.
- Service ghi log và gọi `/api/health` của OGK-Server qua HTTPS thành công.
- Phần logic chạy được pytest trên Mac mà không cần pywin32.

## Kết quả

Agent Service chạy được trên máy ảo và kết nối được tới OGK-Server.

## Phase con và task

ID phase con dạng P3.n theo thứ tự app. ID task dạng P3.n.k.

### P3.1: ogk-agent/service

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P3.1.1 | Dựng máy ảo Windows 11 ARM trong UTM hoặc Parallels; tạo tài khoản admin và tài khoản trẻ chuẩn | Tài khoản trẻ không thuộc nhóm Administrators |
| P3.1.2 | Chụp snapshot sạch của máy ảo | Khôi phục được snapshot |
| P3.1.3 | Cài Python 3.12 x64; cài thử pywin32, psutil, PyInstaller, cryptography, dnslib | Import đủ thư viện dưới giả lập x64 không lỗi |
| P3.1.4 | Tạo ogk-agent với requirements.txt và cấu trúc `service/core`, `service/modules`, `service/platform` theo PLAN.md | Cài đặt bằng một lệnh |
| P3.1.5 | Khung Windows Service bằng win32serviceutil, chạy asyncio event loop trong service, dừng sạch khi SCM yêu cầu | Start và Stop trong Services.msc không treo |
| P3.1.6 | Cấu hình Service Recovery tự khởi động lại khi lỗi | Kill tiến trình thì SCM bật lại |

| P3.1.8 | Gọi `/api/health` của server qua HTTPS bằng CA tự ký | Log ghi trạng thái server |
| P3.1.9 | Build `ogk-service.exe` bằng PyInstaller x64 | Exe chạy được như service |
