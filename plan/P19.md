# P19: Ngân sách theo nhóm ứng dụng (NÊN CÓ, tùy chọn)

Phase của đồ án OGK: ứng dụng hỗ trợ quản lý việc sử dụng máy tính của trẻ em.

| Mục | Nội dung |
| :---- | :---- |
| Cần xong trước | P12, P13 |
| App | ogk-server, ogk-dashboard, ogk-agent/service, ogk-agent/tray |
| Kiểm thử | pytest trên Mac; mục có nhãn (máy ảo) chạy trên máy ảo Windows 11 ARM, đăng nhập tài khoản trẻ |

## Mục tiêu

Mỗi nhóm ứng dụng có ngân sách thời gian riêng, ví dụ học tập không giới hạn, trò chơi 45 phút. Bộ đếm theo nhóm chạy độc lập với quota ngày. Hết ngân sách nhóm thì chặn ứng dụng thuộc nhóm đó, không khóa máy. Chỉ làm khi đã xong mọi phase bắt buộc.

## Kiểm tra nghiệm thu

- Học tập không giới hạn và trò chơi 45 phút: hai bộ đếm chạy độc lập và đúng (máy ảo).
- Hết ngân sách trò chơi thì ứng dụng trò chơi bị chặn có giải thích, ứng dụng học tập vẫn dùng được (máy ảo).

## Kết quả

Phụ huynh giới hạn được thời gian theo từng nhóm ứng dụng.

## Phase con và task

ID phase con dạng P19.n theo thứ tự app. ID task dạng P19.n.k.

### P19.1: ogk-server

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P19.1.1 | Gán nhóm cho ứng dụng; thêm ngân sách theo nhóm vào lược đồ chính sách; ghi nhật ký kiểm toán | Có test lược đồ |

### P19.2: ogk-dashboard

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P19.2.1 | Form ngân sách theo nhóm trong `features/screentime` | Lưu và đọc lại đúng |

| ID | Task | Xong khi |
| :---- | :---- | :---- |
| P19.3.1 | Thêm bộ đếm theo nhóm dựa trên ứng dụng ở cửa sổ trước | Hai bộ đếm độc lập |
| P19.3.2 | Hết ngân sách nhóm thì chặn ứng dụng thuộc nhóm qua appcontrol | Ứng dụng nhóm khác vẫn chạy |
| P19.3.3 | Build lại agent trong máy ảo, thay exe tại chỗ, chạy mọi mục nghiệm thu có nhãn (máy ảo); sửa lỗi chỉ có trên Windows | Mọi mục (máy ảo) qua |
